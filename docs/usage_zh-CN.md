# 使用手册

## 首次使用

系统初始无任何账号。打开登录页面后点击"注册"，输入用户名和密码，**第一个注册的用户自动成为管理员**。

管理员登录后可通过侧边栏齿轮菜单 → "添加用户" 为其他人创建账号。

之后访问的任何人只能通过管理员创建的账号登录，公开注册已关闭。

## 界面说明

- **左侧分类栏（Sidebar）**：顶部为按钮行——齿轮菜单（导入/导出 HTML、补齐图标、链接检测、语言切换、修改密码）、新增（+）、退出登录、主题切换；下方为分类树，支持展开/折叠、拖拽排序、右键菜单
- **右侧内容区**：分组标题 + 搜索框 + 当前分类下的书签卡片网格，支持拖拽排序

## 功能操作

### 账号管理

- **修改密码**：侧边栏齿轮菜单 → "修改密码"，输入原密码和新密码
- **添加用户**（管理员）：侧边栏齿轮菜单 → "添加用户"，输入用户名和密码。可查看用户列表和删除普通用户
- **退出登录**：侧边栏退出按钮

### 分类管理

- **新建分类**：点击顶部 "+" → "新建文件夹"，或在左侧分类树上右键 → "新建文件夹"
- **重命名分类**：左侧分类树上右键 → "重命名"
- **删除分类**：拖拽分类到右下角垃圾桶，或右键 → "删除"（会同时删除该分类及其子分类下的全部书签）
- **拖拽排序**：在左侧分类树上直接拖拽

### 书签管理

- **新建书签**：点击顶部 "+" → "新建书签"，保存后自动抓取网站图标并转存为本地 base64，之后进站不再请求外部图标服务
- **补齐图标**：齿轮菜单 → "补齐图标"，为缺失图标的书签（或旧版本遗留的外链图标）批量抓取并本地化
- **编辑书签**：点击书签卡片右下角的编辑按钮
- **删除书签**：拖拽书签到右下角垃圾桶，或点击编辑后删除
- **拖拽排序**：在右侧书签区直接拖拽卡片重新排列
- **移动分类**：拖拽书签到左侧分类树的某个节点上

### 搜索

在右侧搜索框输入关键词，**输入即实时过滤**书签，支持标题/网址模糊匹配与拼音（如输入 `github` 或 `gitub`）。

### 导入 / 导出

侧边栏齿轮菜单：

- **导出 HTML**：下载浏览器兼容的书签 HTML 文件
- **导入 HTML**：上传浏览器导出的标准书签 HTML 文件，保留分类层级

### 链接检测

侧边栏齿轮菜单 → **检测失效链接**：

1. 点击后对所有书签逐一发送 HTTP HEAD 请求探测存活状态，弹窗内实时显示进度（已检测 X/Y）
2. 完成后按结果分组展示：**正常 / 页面失效 / 站点不可达 / 可疑跳转**（跨域名重定向）
3. 结果行带 `缓存` 标记表示来自 24h 内缓存；点击“✓”可将失效书签标记为正常，点击行或编辑按钮可直接跳转编辑该书签
4. 检测只读，不会修改任何数据

### 界面设置

侧边栏按钮：

- **中英文切换**：齿轮菜单 → 中文 / English
- **暗色 / 亮色模式**：主题切换按钮

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| Enter（密码框） | 触发登录 |
| Enter（新建分类输入框） | 保存分类名 |
